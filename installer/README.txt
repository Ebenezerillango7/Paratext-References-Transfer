========================================================================
 Parallel References Transfer Plugin for Paratext 9.5+
========================================================================

QUICK INSTALLATION:
-------------------
1. Make sure Paratext 9 is closed.
2. Double-click "install-plugin.bat".
3. Wait for the "[OK] Installation completed successfully!" popup.
4. Open Paratext 9.
5. In the top menu bar, click:
   Tools -> Transfer Parallel Passage References...

UNINSTALLATION:
---------------
1. Close Paratext 9.
2. Double-click "uninstall-plugin.bat" (or use "Uninstall Plugin..." inside the plugin).

REQUIREMENTS:
-------------
- Windows 10 or Windows 11
- Paratext 9.5 or later
